# Phase 4a Output Formats

## §Consolidated-Review-Format

The consolidated review is a **read-only evidence artifact**: the tech lead does not write
resolutions here. It must follow this structure so findings can be traced back to sources; the
tech lead's actual ACCEPT/REJECT/MODIFY decisions are written in the separate
`resolutions-v<N+1>.md` file generated by Phase 4c.

Merged finding ID format and the disposition vocabulary (`CONFIRMED` / `CONFLICTED` /
`DISMISSED`) are defined normatively in `SKILL.md §4a`; this skeleton specifies layout only.

```markdown
# Consolidated Review: <plan-name> v<N>
**Date:** <ISO date>
**Models:** <model-1> · <model-2> · <model-3>
**Plan:** <plan-path>

---

## 2. Carried Forward Findings

*Findings carried forward from prior resolutions due to PHASE-4B-SKIP or unresolved
QUESTION FOR TECH LEAD entries. Each entry includes a `Carried from:` annotation with the
source resolutions file path and the original finding ID, so the TL can trace the origin
without opening prior files. If no findings are carried forward this round, this section
may be omitted.*
```
